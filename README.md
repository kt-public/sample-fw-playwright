# Playwright FW Exercises

Project contains Playwright FW exercises

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Run all tests

   ```bash
   npm run test:all
   ```

3. Run tests by Playwright UI

   ```bash
   npm run test:ui
   ```

4. Show test report
   ```bash
   npm run report
   ```
