# Playwright FW Exercises

Project contains Playwright FW exercises

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Run all tests

   ```bash
   npm run test:all
   ```

3. Run tests by Playwright UI

   ```bash
   npm run test:ui
   ```

4. Show test report

   - Show playwright report

   ```bash
   npm run report:html
   ```

   - Show allure report
   ```bash
   npm run report:allure
   ```

## Test cases

1. Add single product to cart - [cart.spec.ts](./tests/cart.spec.ts)

2. Checkout with valid receiver information - [checkout.spec.ts](./tests/checkout.spec.ts)

3. Update full name in profile - [profile.spec.ts](./tests/profile.spec.ts)
